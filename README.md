# Irrevocable Trust — Estate Planning & Financial Literacy Course

Private course file generated from OpenMAIC framework.

## Contents
- `OpenMAIC_Trust_Course.html` — interactive HTML classroom (9 sections)
  - Irrevocable trust definition & funding steps
  - Estate planning integration (will, POA, health proxy)
  - Financial literacy actions (balance sheet, gift exclusions, beneficiary review)
  - Trust-building practices
  - Questionnaire with live score calculator
  - Trust document template (Schedules A–G)
  - Meeting minutes template
  - Accounting & tax documents (Form 1041, Schedule K-1, gift exclusions)

## Usage
- Open `OpenMAIC_Trust_Course.html` in a browser
- Click "Calculate Score" in Section 6 for readiness assessment
- Not legal advice — consult estate attorney / CPA
